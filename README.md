# Python Utility Collection

A small collection of beginner-friendly Python scripts for everyday text, finance, encoding, password, networking, and currency tasks.

This repository is designed as a simple learning project for Python beginners. Each script focuses on a practical task and demonstrates core Python concepts such as file handling, JSON processing, string manipulation, user input, randomness, and basic networking.

---

## Files in this Repository

### `currency_converter.py`
Converts one currency value into another using exchange-rate data from the project.

- Works together with `rates.json` to read the conversion rates needed by the script.
- Demonstrates JSON handling and numeric calculations in Python.

---

### `finance_calculator.py`
Performs basic financial calculations such as interest or repayment-related computations.

- Useful for quick command-line finance practice.
- Demonstrates mathematical operations and user input handling.

---

### `morse_code.py`
Encodes plain text into Morse code or decodes Morse code back into readable text.

- Demonstrates character mapping and string processing in Python.
- A simple example of encoding and decoding logic.

---

### `password.py`
Generates or manages passwords based on the script logic included in the file.

- Useful for practicing randomness and validation techniques.
- Demonstrates working with user input and secure password concepts.

---

### `text_analyser.py`
Analyzes text content from a file or user input to produce basic text statistics.

- Can count words, characters, or other simple metrics depending on implementation.
- Pairs with `demo_file.txt` for quick testing.

---

### `website_status.py`
Checks whether a website is reachable or returns a valid response status.

- Demonstrates how Python can make simple web requests.
- Useful for learning basic networking and HTTP response handling.

---

## Purpose of the Project

This repository serves as a beginner-friendly Python practice collection. Each file focuses on solving a small real-world problem while introducing important programming concepts in a simple and understandable way.
