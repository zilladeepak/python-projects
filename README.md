Python Utility Collection
A small collection of beginner-friendly Python scripts for everyday text, finance, encoding, password, networking, and currency tasks. A good README should explain what the project does and help users navigate the repository clearly, so this version focuses on a short project overview and a file-by-file summary.

Files in this repository
currency_converter.py
Converts one currency value into another using exchange-rate data from the project.

Works together with rates.json to read the conversion rates needed by the script.

demo_file.txt
Sample input file used to test or demonstrate the text analysis script.

Helps users quickly try text_analyser.py without creating their own text file first.

finance_calculator.py
Performs basic financial calculations such as interest or repayment-related computations.

Useful for quick command-line finance practice and simple money calculations.

morse_code.py
Encodes plain text into Morse code or decodes Morse code back into readable text.

Shows how character mapping and string processing can be handled in Python.

password.py
Generates or manages passwords based on the script logic included in the file.

Useful as a simple practice project for randomness, validation, or user input handling.

rates.json
Stores the exchange-rate data used by the currency converter.

Keeps rate information separate from the Python code, making updates easier.

text_analyser.py
Analyzes text content from a file or user input to produce basic text statistics.

Pairs with demo_file.txt so the script can be tested immediately.

website_status.py
Checks whether a website is reachable or returns a valid response status.

Useful for learning how Python can make simple web requests and report results
